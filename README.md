# BREAK RUSH — NEON OVERDRIVE

Ayuが企画・プロデュースする、ネオンアーケード×ローグライクのブラウザゲームです。

- **企画・プロデュース:** Ayu
- **実装:** HTML Canvas / CSS / JavaScript（AI支援を活用して開発）
- **対応:** PC・スマートフォンのモダンブラウザ
- **料金:** ゲーム本体は無料。外部ライブラリや有料APIは不要

## 公開URL

GitHub Pagesで公開設定すると、`https://ayu11039.github.io/break-rush/` で遊べます。公開設定が完了する前はこのURLは有効ではありません。

## 公開する方法

1. リポジトリ `ayu11039/break-rush` の **Settings → Pages** を開きます。
2. **Build and deployment → Source** を `Deploy from a branch` にします。
3. Branchを `main`、フォルダを `/(root)` にして保存します。
4. 数分後にURLを開き、表示と操作を確認します。

## セーブと再開

- プレイ中のランは約2秒ごととページを閉じる際に自動保存されます。
- 同じURL・同じブラウザで開き直すと、タイトル画面に「CONTINUE YOUR RUN」が表示されます。
- スコア、実績、ジェム、スキン、永続強化、設定、ステージラボの配置もブラウザ内に保存されます。
- プライベートブラウズ、サイトデータ削除、別ブラウザ・別端末ではセーブが引き継がれないことがあります。
- 「設定」からJSONバックアップを書き出し・復元できます。
- オンラインランキングやクラウド同期は未実装です。
