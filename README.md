# BREAK RUSH — NEON OVERDRIVE

個人公開用の静的ブラウザゲームです。ゲーム本体は `index.html` だけで動き、外部ライブラリや有料APIは必要ありません。

## GitHub Pages で自分のURLに公開する

1. GitHub にログインし、`break-rush` という名前の **Public** リポジトリを新規作成します。
2. このフォルダ内の `index.html` と `.nojekyll` をリポジトリの一番上（root）にアップロードして commit します。
3. リポジトリの **Settings → Pages** を開き、Build and deployment を **Deploy from a branch**、Branch を **main**、Folder を **/ (root)** にして Save します。
4. 公開処理が終わると、URL は `https://ayu11039.github.io/break-rush/` になります（リポジトリ名やアカウント設定が違う場合はURLも変わります）。このURLは公開設定を完了するまで有効にはなりません。

## セーブについて

- 進行中のゲームは約2秒ごとに自動保存し、ページを閉じた後も、同じURL・同じブラウザで開けばタイトルの「CONTINUE YOUR RUN / 続きから再開」から再開できます。
- ハイスコア、実績、ジェム、スキン、ワークショップ、設定、ステージラボの配置もブラウザに保存されます。
- ブラウザのサイトデータや履歴の一部を削除した場合、プライベートブラウズで遊んだ場合、別のブラウザ・端末を使った場合は、保存が引き継がれないことがあります。
- 「設定」からセーブデータをJSON形式で書き出し・読み込みできます。公開前やブラウザを変更する前にバックアップしてください。
- オンラインランキングやクラウド同期は含まれていません。保存は同じブラウザ内のローカル保存です。

## ローカルで遊ぶ

`index.html` を Edge または Chrome で開いても遊べます。ただし、保存を安定させるため、可能なら GitHub Pages の HTTPS URL から利用してください。
